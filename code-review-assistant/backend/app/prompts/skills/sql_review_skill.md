## SQL 审查技能

当变更涉及 `.sql`、`mapper.xml`、JPA/MyBatis SQL 片段时，重点检查：

1. 索引与执行计划风险
- 是否出现全表扫描、函数包裹索引列、隐式类型转换导致索引失效。
- `OR` / `%like%` / 大范围 `IN` 是否可能导致慢查询。

2. 正确性风险
- `JOIN` 条件是否完整，是否可能造成笛卡尔积或重复计数。
- 聚合与分组是否与业务语义一致（`GROUP BY` 与非聚合列）。
- 时间区间边界（闭开区间）和时区处理是否一致。

3. 数据安全与隔离
- 是否缺少租户、仓库、组织等隔离条件。
- 是否存在危险写操作（误删/误更新）且缺少保护条件。

4. 性能与可维护性
- 分页是否稳定（排序字段、覆盖索引、深分页策略）。
- 复杂 SQL 是否拆分或增加注释说明，避免后续误改。
