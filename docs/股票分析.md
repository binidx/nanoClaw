# 股票分析

## 模块定位

股票分析是独立子系统，不是聊天页里的一个小插件。

默认情况下，Web 控制台不会显示股票分析导航入口。
需要先在“配置”页开启“股票分析”开关，导航栏才会出现对应入口。

## 当前能力

- 分析配置读取与保存
- 配置预设管理
- watchlist 管理
- 分析任务发起、删除、重试、清理
- 历史报告与详情
- 报告校验
- 反馈快照
- 市场复盘
- 回测
- 数据源状态查看

## 使用流程

1. 在股票分析页确认配置
2. 按需要选择市场范围、策略或预设
3. 维护 watchlist 或直接发起分析
4. 查看任务状态与历史报告
5. 结合反馈快照、市场复盘和回测结果做复盘

## 报告内容侧重点

从代码结构看，报告会涉及：

- 技术指标
- 因子分析
- 新闻情报
- 交易计划
- 校验与风险提示

## 数据与任务

- 后端维护独立的股票分析任务队列
- 支持实时任务流
- 支持历史记录和反馈沉淀
- 支持数据源状态查看

## 风险声明

- 这不是投资建议
- 数据源可能延迟、失败或回退
- AI 总结可能出现错误归纳或幻觉
- 回测结果不能等价于真实收益
