# 快速开始

## 环境要求

**必需：**

- Node.js 20+
- `npm`
- 至少一个可用的 AI Provider

**推荐安装（Agent 工具增强）：**

| 工具 | 用途 | 安装方式 |
|------|------|----------|
| **ripgrep (rg)** | Agent 的 grep/glob 工具使用 rg 进行高速搜索。缺失时自动回退到 Node.js 内置方案（较慢） | macOS: `brew install ripgrep`<br>Debian/Ubuntu: `apt-get install ripgrep`<br>Fedora: `dnf install ripgrep`<br>Windows: `winget install BurntSushi.ripgrep.MSVC` |
| **Git** | 代码仓库操作 | 各平台包管理器安装 |

**可选（语言特定 Lint 工具）：**

| 工具 | 用途 | 安装方式 |
|------|------|----------|
| ruff | Python 代码检查 | `pip install ruff` |
| go | Go 代码检查 | https://go.dev/dl/ |
| cargo | Rust 代码检查 | https://rustup.rs/ |

> 语言特定的 lint 工具仅在 Agent 对对应语言文件运行 `read_lints` 时需要。缺失时会返回友好提示，不影响其他功能。

**其他可选依赖：**

- 原生目录选择器
- 浏览器可执行文件（用于渲染抓取）

## 推荐安装步骤

```bash
npm install
cd web && npm install
cd ../agent/runner && npm install && npm run build
cd ..
npm run build
npm run onboard
```

Windows：

```bat
npm install
cd web && npm install
cd ..\agent\runner && npm install && npm run build
cd ..\..
npm run build
npm run onboard
```

## `setup.sh` 和 `npm run onboard` 的区别

- `setup.sh` / `setup.ps1`
  只做根目录依赖安装与基础环境检查，不会替你装好 `web/` 和 `agent/runner/`
- `npm run onboard`
  用于补齐首次启动所需的本地运行目录、数据库和安全模板

如果你只执行了 `setup.sh`，仍然需要手动安装前端和 agent runner 依赖。

## 启动

macOS / Linux：

```bash
./start.sh
```

Windows：

```bat
start.bat
```

启动脚本会：

1. 停掉旧进程
2. 清理 `dist` 和 `web/dist`
3. 构建后端与前端
4. 启动运行时并写入 PID/port 标记文件

## 首次进入后建议做什么

1. 在“配置”页添加默认 AI Provider
2. 视需要打开 Web 登录或浏览器能力
3. 配置一个 Assistant
4. 需要外部接入时再配置渠道实例
5. 按需进入任务、Repo Review 或股票分析页面；如果看不到“股票分析”，先到“配置”页开启该入口

## 常用检查

```bash
npm run doctor
npm run onboard -- --check --json
npm run build:all
```

## 最容易踩坑的地方

- 忘记执行 `cd web && npm install`
- 忘记执行 `cd agent/runner && npm install && npm run build`
- 没有先配置 Provider 就直接进入聊天
- 把本项目误当成远端托管服务，而不是本机工作台
- Agent 报 `grep error: spawnSync rg ENOENT` — 需要安装 ripgrep，参考上方"推荐安装"表格
